# AC World Gamma v0.3.0

First public release of AC World Gamma, a lightweight Decal plugin for Asheron's Call.

## Features

- Changes brightness of the 3D world only
- Leaves chat, radar, inventory, spell bars and other UI unchanged
- Works in windowed mode
- Works in fullscreen mode
- Text commands only; no extra HUD or slider
- Brightness levels 0 through 25
- Remembers the selected level between sessions
- Standalone at runtime

## Commands

```text
/acgamma on
/acgamma off
/acgamma 0
/acgamma 1
...
/acgamma 25
/acgamma up
/acgamma down
/acgamma reset
/acgamma status
/acgamma help
```

## Installation

Close Asheron's Call and run:

`AC World Gamma Setup v0.3.0.exe`

Default installation folder:

`C:\Games\Decal Plugins\AC World Gamma`

## Tested

v0.3.0 was tested successfully with Decal in both windowed and fullscreen AC.
